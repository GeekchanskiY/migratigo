# migratigo

Migratigo is yet another lightweight migration tool.

## Usage

Installation:

```shell
go get github.com/GeekchanskiY/migratigo
```


To install additional cli utilities
```shell
go install github.com/GeekchanskiY/migratigo/cmd/migratigo
```
